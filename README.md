# hopeSerendipity's Blog

个人博客：<https://hopeSerendipity.github.io/>

## 写作方式

1. 在本仓库创建一个 GitHub Issue。
2. Issue 标题是文章标题，正文使用 Markdown。
3. 编辑 Issue 或添加评论后，GitHub Actions 会自动重新构建并发布博客。

- [写一篇新文章](https://github.com/hopeSerendipity/hopeSerendipity.github.io/issues/new)
- [查看部署状态](https://github.com/hopeSerendipity/hopeSerendipity.github.io/actions)
